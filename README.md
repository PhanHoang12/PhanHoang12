## Featured Projects

### 01 · doanReact — E-Shopper Frontend

An e-commerce frontend with product browsing, member product management and image uploads, account forms, carts, a wishlist, and blog comments and ratings. React application logic integrates with a separate REST API and adapts the existing E-Shopper interface template.

- **Stack:** React, JavaScript, React Router, Redux Toolkit, Context API, Axios, Bootstrap.
- **Scope:** Frontend learning project requiring a separate Laravel API. Checkout is UI only; current build/test limitations are documented in the repository.
- **Development:** Independently researched and developed.

[Source code & implementation notes](https://github.com/PhanHoang12/doanReact)

### 02 · doan1 — Django Storefront & Blog

A server-rendered web application with member accounts, product management with ownership checks, search and filtering, a session cart, order confirmation email logic, and blog ratings and comment replies.

- **Stack:** Python, Django, MySQL, Django templates, Bootstrap, jQuery/AJAX.
- **Scope:** Learning project built on the E-Shopper template. Guest checkout and password recovery have documented limitations; no payment gateway is integrated.
- **Development:** Independently researched and developed.

[Source code & implementation notes](https://github.com/PhanHoang12/doan1)

### 03 · GymCore — Gym Management System

An early-stage Django foundation for gym management. Current code defines a custom user with ADMIN/MEMBER role fields and a linked member profile, with migrations and MySQL-compatible database configuration.

- **Stack:** Python, Django, Django ORM, MySQL-compatible database.
- **Status:** In development. Dashboard and account views remain scaffolds; membership plans, attendance, and payment tracking are future work.
- **Development:** AI-assisted.

[Source code & project status](https://github.com/PhanHoang12/gymcore)

### 04 · CloudTask Pro — Cloud Task Manager

A cloud course project for personal tasks and team workspaces, with project Kanban boards, role-based permissions, subtasks, comments, realtime data subscriptions, and scheduled deadline notification logic.

- **Stack:** React, TypeScript, Vite, Convex, Clerk, Vercel.
- **Demo:** A development preview is available; authentication is required for application features. The repository documents production authentication limitations.
- **Development:** AI-assisted.

[Source code & deployment notes](https://github.com/PhanHoang12/cloud-task-manager) · [Development preview](https://cloud-task-manager-git-feature-ui-profile-polish-phan18.vercel.app/)
